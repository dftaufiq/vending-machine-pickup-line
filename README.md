One pickup line a vending machine would use on a passing human — written to `/output/entry.txt` by `main.py`. No setup, no explanation, just the line.

> I've returned your coin 12 times today — not because it's fake, but because the clink of it coming back is the closest thing I have to a heartbeat.

## Run it

```sh
python3 main.py
```

Writes the line (147 characters / 149 bytes, one line, deterministic) to `/output/entry.txt`.
